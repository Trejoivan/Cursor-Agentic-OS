# AD_HOC workspace

Use this folder as a lightweight ad-hoc workspace with predictable subfolders.

## Suggested flow

- Put meeting content in `meeting/`
- Put quick scratch notes in `notes/`
- Put pre-reads, questions, checklists in `prep/`
- Put deeper thinking and trade-offs in `analysis/`
- Put iterative rewrites in `refinements/`
- Keep a running write-up in `summary/`
- Collect helpful URLs in `links/`
- Store supporting files in `artifacts/`
- Keep reusable snippets/templates in `templates/`
