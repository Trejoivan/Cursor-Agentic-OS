# prep/

Use this folder for “getting ready” work: checklists, questions, pre-reads, context dumps.

## Suggested files

- `CHECKLIST.md`: your prep checklist
- `QUESTIONS.md`: questions to answer / ask
- `PREREADS.md`: links + short notes on what to read
- `CONTEXT.md`: background/context you don’t want to lose

## Quick prompts

- What does “done” look like for this task?
- What information do I need before deciding?
- Who do I need input from?
