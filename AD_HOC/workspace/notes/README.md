# notes/

Use this folder for scratch notes that don’t belong anywhere else yet.

## Suggested files

- `SCRATCH.md`: quick ideas, fragments, TODOs
- `QUESTIONS.md`: open questions you want answered
- `ASSUMPTIONS.md`: assumptions you’re currently operating under

## Tips

- Keep **one idea per bullet** so it’s easy to summarize later.
- When something turns into a decision, move it to `summary/` (or `meeting/DECISIONS.md` if it’s meeting-driven).
