# archive-summaries/

“Consumed” summaries live here once they’ve been used for BMAD prep / ingest formatting, so you don’t repeat the BMAD prep work.

## How it works

- Fresh transcript summaries land in `../transcript-summaries/`
- When you request **BMAD ingest formatting**, the agent:
  - saves the BMAD-ready output here, and
  - archives any source summaries it used here as well (so `../transcript-summaries/` stays a “to-prep” queue)

## Suggested naming

- `YYYY-MM-DD - <meeting name> - bmad-prep.md`
