# transcript-summaries/

Landing zone for summaries created from transcripts (clean notes, decisions, action items).

If you later request BMAD ingest formatting from these summaries, the agent should move the “consumed” summaries into `../archive-summaries/` so you don’t re-run BMAD prep.

## Suggested naming

- `YYYY-MM-DD - <meeting name> - summary.md`

## Suggested structure

- **Summary** (3–7 bullets)
- **Decisions**
- **Action items** (owner + due date)
- **Open questions / follow-ups**
