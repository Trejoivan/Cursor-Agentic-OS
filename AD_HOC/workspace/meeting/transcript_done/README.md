# transcript_done/

Reviewed/processed transcripts live here so you don’t accidentally ask for a re-review.

## How it works

- Put new transcripts in `../transcripts/`
- When you ask for a transcript summary, the agent writes the summary to `../transcript-summaries/`
- Then the agent **moves** the transcript here (so `../transcripts/` stays as an “inbox”)

## Suggested naming

- `YYYY-MM-DD - <meeting name> - transcript.txt`
