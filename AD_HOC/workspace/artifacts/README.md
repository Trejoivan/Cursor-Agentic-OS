# artifacts/

Use this folder for supporting files that don’t fit cleanly into markdown notes.

## Examples

- exports/screenshots
- diagrams
- snippets and drafts
- PDFs you’re referencing (if you keep them in-repo)

## Tip

If you add non-text artifacts here and want to keep the repo clean, consider ignoring them via `.gitignore` and keeping only lightweight pointers in `links/LINKS.md`.
