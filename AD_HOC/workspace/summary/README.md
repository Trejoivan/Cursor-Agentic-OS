# summary/

Use this folder for the “current best” write-up you’d share with someone else.

## Suggested files

- `DRAFT.md`: the running summary you keep updating
- `FINAL.md`: a polished version (when ready)
- `DECISIONS.md`: final decisions + rationale
- `NEXT-STEPS.md`: actions and owners (if applicable)

## Quick prompts

- What happened / what did we learn (in 3–7 bullets)?
- What decisions were made?
- What’s next (who does what by when)?
