# analysis/

Use this folder for structured thinking: options, trade-offs, calculations, pros/cons, and recommendations.

## Suggested files

- `ANALYSIS.md`: the main analysis write-up
- `OPTIONS.md`: options list (with constraints)
- `TRADEOFFS.md`: explicit trade-offs and risks

## Quick prompts

- What constraints are fixed vs flexible?
- What are 2–5 realistic options?
- What’s the main risk for each option?
- What’s the recommendation and why?
