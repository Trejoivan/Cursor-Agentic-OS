# refinements/

Use this folder for iterative rewrites and “versions” of a deliverable (agenda, email draft, proposal, outline, etc.).

## Suggested files

- `V1.md`, `V2.md`, `V3.md`: versioned drafts
- `CHANGELOG.md`: what changed between versions (optional)

## Tips

- Keep older versions (don’t overwrite) so you can compare.
- If a draft becomes final, copy it into `summary/FINAL.md`.
