# AD_HOC Meetings (prep & scratch space)

This folder is a **scratch / prep workspace** for meeting-related work that’s typically ad-hoc:

- `AD_HOC/Meetings/`

Recommended structure (all private by default):

- `AD_HOC/Meetings/prep/` — prep docs (what to cover, risks, history summary)
- `AD_HOC/Meetings/agendas/` — draft agendas (or use `/cag`)
- `AD_HOC/Meetings/transcripts/` — raw transcripts you paste in before processing

**Canonical records** (final meeting notes, decisions, action items, people history) are stored in `meeting-os/` under:

- `meeting-os/Meetings/`
- `meeting-os/Decisions/`
- `meeting-os/Actions/`
- `meeting-os/People/`
