# work-os for Technical Product Managers

Clarify problems, align stakeholders, ship outcomes, and build a portfolio of impact.

## Why work-os for Technical Product Management?

As a Technical PM, you’re managing:
- **Ambiguity** — turning messy asks into crisp problems and decisions
- **Alignment** — coordinating engineering, design, GTM, support, leadership
- **Execution** — roadmap slices, dependencies, risks, delivery comms
- **Strategy** — metrics, user insights, trade-offs, narrative

work-os helps you keep threads straight and convert daily work into durable artifacts (decisions, status, wins).

---

## Setup for Technical PMs (10 minutes)

### 1. Define Your Goals

Open `GOALS.md` and add your objectives:

```markdown
# Goals

## This Quarter
1. Ship [initiative] with [success metric] (adoption, revenue, retention, cost)
2. Improve execution reliability (reduce slips / improve dependency clarity)
3. Build stakeholder trust via consistent, high-signal updates
4. Career growth: strengthen [technical depth | strategy | leadership]

## Key Metrics
- Adoption / activation
- Retention / churn
- Revenue / pipeline influenced (if relevant)
- Delivery health (on-time rate, risk burn-down)

## Focus Areas
- Discovery & problem definition
- Planning & alignment
- Execution & delivery
- Customer & stakeholder communication
```

### 2. Tell Cursor About Your Work

```
You: "I'm a Technical Product Manager working on [area]. I run discovery, write PRDs,
     align stakeholders, and partner with engineering on delivery."
```

Cursor will tailor categories like:

```
Active/
├── discovery/          # Research, insights, problem framing
├── planning/           # Roadmap slices, PRDs, specs, dependencies
├── delivery/           # Execution tracking, risks, milestones
├── stakeholders/       # Alignment threads, follow-ups, approvals
├── comms/              # Status updates, narratives, launch comms
└── growth/             # Skill-building + career portfolio work
```

## Daily Technical PM Workflow

### Morning
```
You: "What should I work on today?"
```

Cursor should bias toward unblockers: decisions pending, risk hotspots, cross-team dependencies, and stakeholder asks that gate delivery.

### During Work
Capture threads as they happen:

```
"Add to backlog: Decision needed: choose between approach A vs B for [initiative]"
"Add to backlog: Stakeholder X concerns about scope — schedule alignment"
"Add to backlog: Need user interviews for [persona] before finalizing PRD"
"Add to backlog: Draft weekly status update for leadership"
```

### End of Day
```
You: "Process my backlog"
```

## Technical-PM-Specific Workflows

### 1) Decision Tracking (the “decision log” habit)
```
You: "Turn these notes into 2-3 decisions, owners, and next steps. Highlight what’s still ambiguous."
```

### 2) Risk & Dependency Management
```
You: "Given this project update: [paste], list the top risks, leading indicators, and mitigation tasks."
```

### 3) Stakeholder-Ready Status Updates
```
You: "Generate a concise status update (what changed, current health, risks, asks) for [initiative]."
```

---

## What Counts as Urgent for Technical PMs

- Pending decisions that block engineering work
- Exec/customer escalations or time-sensitive commitments
- Critical risks likely to slip a milestone without intervention

## What Counts as Important for Technical PMs

- Clear problem framing and success metrics
- Reducing uncertainty (research, prototypes, spikes)
- Alignment work that prevents downstream rework
- Portfolio-quality artifacts: PRDs, launch narratives, impact summaries

## Skill Growth “Coach Mode” (use as an agent)

### Product sense + technical depth
```
You: "Act as my Technical PM coach. Ask me the key questions I should answer to ship a great PRD for [problem], then critique my answers."
```

### Leadership communication practice
```
You: "Coach me on writing a sharper exec update. Here’s my draft: [paste]. Rewrite it and explain what changed."
```

### Career pathing
```
You: "Help me build a 90-day growth plan to become a stronger Technical PM in [domain]. Include weekly drills and portfolio deliverables."
```
