# work-os for Solution Managers

Deliver outcomes across customers, product, and engineering—without losing critical details.

## Why work-os for Solution Management?

As a Solution Manager (or Solutions lead), you’re balancing:
- **Customer reality** — requirements, constraints, timelines, stakeholders
- **Technical translation** — turning business needs into implementable scope
- **Delivery** — onboarding, integrations, adoption plans, escalations
- **Internal alignment** — product feedback loops, prioritization, enablement

work-os helps you track customer threads, internal asks, and repeatable playbooks—while building proof of impact.

---

## Setup for Solution Managers (10 minutes)

### 1. Define Your Goals

Open `GOALS.md` and add your objectives:

```markdown
# Goals

## This Quarter
1. Deliver [X] successful implementations / go-lives
2. Increase adoption of [key feature] across accounts by [X]%
3. Reduce time-to-value for new customers by [X] days
4. Career growth: deepen [technical depth | stakeholder leadership | solution design]

## Key Metrics
- Time-to-value
- Adoption (usage, seats, workflows)
- Escalations (count, severity, resolution time)
- Expansion influence (pipeline, renewals, references)

## Focus Areas
- Implementations & integrations
- Enablement & playbooks
- Customer feedback → product loop
- Executive communication
```

### 2. Tell Cursor About Your Work

```
You: "I'm a Solution Manager. I lead implementations, integrations, and technical discovery
     with customers, and I coordinate with product/engineering on gaps."
```

Cursor will tailor categories like:

```
Active/
├── accounts/           # Customer-specific threads
├── implementations/    # Go-lives, plans, milestones
├── integrations/       # Technical workstreams, APIs, data flows
├── escalations/        # Issues, blockers, executive attention
├── enablement/         # Playbooks, training, internal docs
└── product-feedback/   # Gaps, requests, learnings
```

## Daily Solution Manager Workflow

### Morning
```
You: "What should I work on today?"
```

Cursor should bias toward customer blockers, go-live risks, escalations, and cross-team dependencies.

### During Work
Capture as you go:

```
"Add to backlog: Customer A wants SSO by end of month — confirm scope + dependencies"
"Add to backlog: Integration mapping needed for Customer B (source systems: ...)"
"Add to backlog: Escalation: performance issue impacting rollout"
"Add to backlog: Create a repeatable onboarding checklist from last week’s lessons"
```

### End of Day
```
You: "Process my backlog"
```

## Solution-Manager-Specific Workflows

### 1) Technical Discovery → Implementable Scope
```
You: "Turn these discovery notes into: requirements, assumptions, open questions, and next-step tasks."
```

### 2) Implementation Plan & Risk Tracking
```
You: "Draft an implementation plan with milestones, owners, risks, and a weekly update template for [customer/project]."
```

### 3) Product Feedback That Actually Gets Used
```
You: "Rewrite this customer feedback into a product-ready problem statement with impact, evidence, and acceptance criteria."
```

---

## What Counts as Urgent for Solution Managers

- Go-live blockers and customer escalations
- Time-bound customer commitments (legal/security reviews, launch dates)
- Cross-team dependencies that can stall an implementation

## What Counts as Important for Solution Managers

- Repeatable playbooks that reduce future friction
- Integration patterns and reusable templates
- Strong product feedback loops (clear evidence + prioritization)
- Portfolio-quality wins (before/after metrics, narratives, references)

## Skill Growth “Coach Mode” (use as an agent)

### Solution design practice
```
You: "Act as my Solutions coach. Give me a scenario and have me propose a solution architecture at a high level, then critique it."
```

### Executive communication drills
```
You: "Coach me on an exec escalation update. Ask me for the minimum facts you need, then draft a crisp message."
```

### Career pathing
```
You: "Help me build a 60-day plan to become a stronger Solution Manager in integrations and stakeholder management."
```
