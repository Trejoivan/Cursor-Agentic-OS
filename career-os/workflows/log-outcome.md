# Log Outcome

The user has an interview or application outcome (offer, rejection, withdrawal) to capture, with learnings.

## Process

1. Record the outcome in `Applications/[company]/outcome.md`
2. Capture: what worked, what didn't, stage reached, decision timeline (if offer)
3. Update story outcome logs in `Stories/` for any stories used
4. Extract learnings into `Learnings/`:
   - Communication patterns that worked or failed
   - Domain vocabulary insights
   - Story adjustments needed
   - Items for the never-use list
5. Update the application tracker

## Rules

- Handle rejections constructively — there is always at least one learning
- Push for specifics: "What feedback did they give?"
- If it's an offer, capture compensation details and the decision deadline
- Never show file paths or metadata
