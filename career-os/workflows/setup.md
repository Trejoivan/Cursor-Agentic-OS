# Set Up career-os

Walk the user through building their career management system. About 10 minutes total.

## Before You Start

Check if `Impact-Library/`, `Stories/`, and `Applications/` already exist. If they do, offer to reconfigure rather than starting over.

## Process

### 1. Build the Impact Library

"Let's start by capturing your achievements. Do you have a current resume I can work from? Or we can build from scratch."

If they share a resume:

- Extract achievements into `Impact-Library/` entries
- Ask about metrics for each — "Do you have numbers for this?"

### 2. Create STAR Stories

From the top 3-5 achievements:

- Draft initial STAR stories in `Stories/`
- Add algorithm labels (Question, Delete, Simplify, Accelerate, Automate)
- Note where probe answers are still needed

### 3. Set Up Tracking

Create:

- `Applications/` directory
- `Learnings/` with starter files
- `Resumes/` directory

### 4. Welcome Message

Confirm setup. Suggest natural-language next steps:

- "Tailor my resume for this job description: …"
- "Help me prep for an interview"
- "Log the outcome from this interview"

## Rules

- Never show file paths or YAML
- Keep the conversation natural — 3-4 rounds maximum
- Focus on getting metrics for every achievement
