# outputs/tailored/

Landing zone for resumes tailored to a **specific job posting**.

## Suggested structure

Create one folder per job listing, e.g.:

- `<company> - <role>/`
  - `jd.md`
  - `tailored-resume.md` (or `resume.json` if you use the JSON workflow)
  - `fit-notes.md`

## Tip

If you actually apply, copy the final version into `Applications/<company>/` so it stays connected to interview prep and outcome tracking.
