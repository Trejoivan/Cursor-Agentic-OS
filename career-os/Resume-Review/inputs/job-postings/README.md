# inputs/job-postings/

Drop job postings / job descriptions here.

## Suggested naming

- `YYYY-MM-DD - <company> - <role> - jd.md`
- `YYYY-MM-DD - <company> - <role> - jd.txt`

## Tip

If you capture a posting from the web, a clean `.md`/`.txt` version makes tailoring much easier than a screenshot/PDF.
