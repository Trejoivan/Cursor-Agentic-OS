# inputs/resumes/

Drop your **master resume** files here.

## Suggested naming

- `master - YYYY-MM-DD - resume.pdf`
- `master - YYYY-MM-DD - resume.docx`
- `master - YYYY-MM-DD - resume.md`

## Tip

If you want the assistant to edit the resume directly, keep a text version (`.md` / `.txt`) alongside the PDF/DOCX.
