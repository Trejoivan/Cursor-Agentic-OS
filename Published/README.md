# Published

This folder is the **public/shareable** area of the repo.

Everything under:

- `bmad-projects/<slug>/` (major project ideas)
- `_mini_bmad/runs/...` (ad-hoc runs)

is **gitignored by default** so you can iterate privately.

## How to publish something

When you feel comfortable sharing a project:

1. Create a folder under `Published/` (pick any structure you like).
2. Copy in only the curated artifacts you want visible (sanitized, no private notes).

Examples:

- `Published/projects/<slug>/PRFAQ.md`
- `Published/projects/<slug>/product-brief.md`
- `Published/runs/<run-id>/DELTA-SINCE-LAST.md`

Tip: prefer copying outputs (PRFAQ/brief/summary packs) rather than raw scratch notes.
