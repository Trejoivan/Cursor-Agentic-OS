# Add Task

Capture a task from natural language and organize it behind the scenes.

## Process

1. Parse: task name, urgency, due date, category, possible goal connection
2. Create the task file with proper frontmatter (silently)
3. Confirm in one short line, for example:
   > Got it — added "Book annual physical" to health, due next month.

## Rules

- FAST — capture and confirm in a single exchange
- Never show YAML or file paths
- Mention the goal connection when you see one
- If the input is too vague to file safely, ask one clarifying question
