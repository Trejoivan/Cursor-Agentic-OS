# Set Up personal-os

Guide the user through creating their life management system. About 5 minutes total.

## Before You Start

Check whether `GOALS.md` exists and whether `Tasks/` already has subdirectories. If it is set up, offer to reconfigure rather than starting over.

## The Conversation (3 rounds)

1. **Life areas** — "What areas do you want to manage? Career, relationships, health, finances, projects, learning?"
2. **Priorities** — "For each area, what's your top priority right now?"
3. **Current load** — "Brain dump everything on your plate, and I'll organize it after."

## Build the Workspace

Create:

- `GOALS.md` from their goals, organized by area
- `INBOX.md` (empty)
- `Tasks/` subdirectories by category (for example `health/`, `relationships/`, `learning/`, `admin/`)
- `Knowledge/` directory

## Welcome Message

Confirm the structure and goals you created. Suggest natural-language next steps:

- "Process my inbox"
- "What should I work on today?"
- "Add a task: …"

## Rules

- Never show file paths or YAML
- Cap the conversation at 3 rounds
- About 5 minutes total
